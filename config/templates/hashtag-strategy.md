## Quick Reference: Hashtag Rules

| Rule | Detail |
|------|--------|
| Max per post | 30 |
| Unique per 7 days | 30 (then repeats are free) |
| Placement | Caption (not first comment - less effective now) |
| Case sensitivity | Not case sensitive, but use CamelCase for readability |
| Special chars | Only underscores (_), no dots, dashes, emojis |
| Banned tags | Check monthly - Instagram doesn't notify |
| Shadowban test | Post with only test tag → check Recent tab |

## MCP Commands for Hashtag Research

```bash
# Search hashtag info
instagram-mcp call search_hashtag --args '{"hashtag": "your_tag"}'

# Get top media for hashtag
instagram-mcp call hashtag_top_media --args '{"hashtag": "your_tag"}'

# Get recent media for hashtag
instagram-mcp call hashtag_recent_media --args '{"hashtag": "your_tag"}'

# Compare accounts for their hashtag usage
instagram-mcp call compare_accounts --args '{"accounts": ["comp1", "comp2", "comp3"]}'
```
