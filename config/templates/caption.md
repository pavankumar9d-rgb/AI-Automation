# Caption Template

## Structure Formula
**Hook (1-2 lines) → Value/Story (3-7 lines) → CTA (1 line) → Hashtags**

---

## CTA Library

### Engagement CTAs
- "Comment '{{keyword}}' and I'll DM you the {{resource}}"
- "Which one: {{option_a}} or {{option_b}}? Vote below 🗳️"
- "Tag a friend who needs to see this →"
- "Save this post for later 📌"
- "Share to your story if you agree ↩️"

### Growth CTAs
- "Follow for more {{niche_content}} 👆"
- "Turn on notifications so you don't miss {{series}} 🔔"
- "Link in bio for the full {{guide/tool/template}} 🔗"

### Conversion CTAs
- "DM me '{{keyword}}' for the {{freebie}}"
- "Join {{number}} others in my {{newsletter/community}} → [link]"
- "Spots open for {{offer}} — apply at [link]"

## Hashtag Strategy

### Tier 1: Niche-Specific (5-10)
High relevance, lower volume
```
#{{specific_niche}} #{{sub_niche}} #{{micro_niche}}
```

### Tier 2: Industry/Category (5-10)
Medium relevance, medium volume
```
#{{industry}} #{{category}} #{{topic}}
```

### Tier 3: Broad/Discovery (3-5)
Lower relevance, high volume
```
#{{broad_term}} #{{trending}} #{{viral}}
```

### Tier 4: Branded/Community (1-3)
Unique to you
```
#{{your_brand}} #{{your_series}} #{{your_community}}
```

### Tier 5: Location/Event (0-3)
If applicable
```
#{{city}} #{{event}} #{{local_community}}
```

**Total: 15-30 hashtags max**

---

## Caption Checklist
- [ ] First line stops scroll (hook)
- [ ] Value delivered before CTA
- [ ] Voice matches brand personality
- [ ] Line breaks for readability
- [ ] CTA is clear and singular
- [ ] Hashtags are relevant (not banned)
- [ ] Tagged relevant accounts
- [ ] Location added (if applicable)
- [ ] Alt text written for accessibility
- [ ] No broken links in bio reference
- [ ] Compliance: no prohibited claims
