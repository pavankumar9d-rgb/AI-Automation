# Comment Reply Drafts Template

## Reply Strategy Framework

### Reply Decision Matrix
| Comment Type | Reply? | Timeline | Tone | Template |
|--------------|--------|----------|------|----------|
| Genuine question | ✅ Yes | <1 hr | Helpful, expert | Q&A |
| Compliment | ✅ Yes | <2 hr | Warm, grateful | Appreciation |
| Constructive feedback | ✅ Yes | <4 hr | Open, professional | Feedback |
| Tag/mention friend | ✅ Yes | <2 hr | Friendly, engaging | Tag Response |
| Simple emoji/react | ⚠️ Optional | <1 day | Light, fun | Emoji Reply |
| Spam/irrelevant | ❌ No / Hide | N/A | N/A | Hide/Delete |
| Negative/troll | ⚠️ Case by case | <4 hr | Boundaried, professional | Boundary |
| Complaint/issue | ✅ Yes | <1 hr | Empathetic, solution-oriented | Support |
| Buying intent | ✅ Yes | <30 min | Helpful, directive | Sales |
| UGC/feature request | ✅ Yes | <2 hr | Enthusiastic, inclusive | UGC |

## Reply Templates by Category

### 1. Question & Answer (Educational)
**Trigger:** "How do you...?", "What tool...?", "Can you explain...?"

```
Template A (Direct Answer):
Thanks for asking! {{direct_answer}}. {{additional_context}}. 
If you want the full breakdown, I {{resource_link/bio_link}}. 🙌

Template B (Resource Redirect):
Great question! I actually made a {{reel/carousel/post}} about this exact thing — check it out {{link}}. The key takeaway: {{one_liner}}. 💡

Template C (Personal Experience):
From my experience: {{personal_answer}}. {{caveat_if_any}}. Everyone's different though — what worked for me might need tweaking for you. 🤝

Template D (Community Crowdsource):
Ooh, I'm curious too! {{community_question}}. Anyone else want to weigh in? 👇
```

### 2. Appreciation & Compliments
**Trigger:** "Love this!", "So helpful!", "Amazing content!", "You're inspiring!"

```
Template A (Warm + Question):
Thank you so much! {{specific_appreciation}}. What part resonated most? 💛

Template B (Reciprocal):
Aw, you just made my day! {{personal_touch}}. Keep {{positive_action}} — you're doing great. ✨

Template C (Community Builder):
Thank you! {{name_if_available}}, it means a lot coming from someone who {{acknowledge_their_work}}. Let's connect more — what are you working on? 🤝

Template D (Short & Sweet):
🙏 {{emoji}} Means the world!
```

### 3. Constructive Feedback
**Trigger:** "You missed...", "Actually...", "Correction...", "Disagree because..."

```
Template A (Valid Feedback - Accept):
You're absolutely right — {{acknowledge_specific}}. {{correction/thanks_for_catching}}. Updated my thinking on this. 🎯

Template B (Valid Feedback - Nuance):
Good catch! {{acknowledge}}. The nuance I'd add: {{nuance}}. Thanks for pushing the conversation forward. 💭

Template C (Disagree Respectfully):
Appreciate the perspective! {{acknowledge_their_point}}. My take is {{your_reasoning}} because {{evidence}}. But I love that we can discuss this openly. 🤝

Template D (Clarification Needed):
Thanks for flagging! Could you clarify {{specific_question}}? Want to make sure I address the right thing. 🙏
```

### 6. Boundary Setting (Trolls/Negativity)
**Trigger:** Hate, harassment, bad-faith arguments, off-topic attacks

```

Template B (Disengage):

Template C (Redirect):
```

## Reply Quality Checklist

Before posting ANY reply:
- [ ] Addresses the specific comment (not generic)
- [ ] Matches brand voice
- [ ] Under 2,200 characters (Instagram limit)
- [ ] No typos/grammar errors
- [ ] Appropriate emoji usage (0-3)
- [ ] Includes name if available
- [ ] Adds value (answer, insight, warmth, direction)
- [ ] CTA only if natural (not forced)
- [ ] No controversial topics unless intentional
- [ ] Compliance: no medical/financial/legal advice unless qualified

## Batch Reply Workflow

### Daily Comment Triage (15 mins)
```
1. Run: instagram-mcp call read_all_comments --args '{"limit": 50}'
2. Filter: Categorize each comment (Question/Compliment/Feedback/Tag/Spam/Complaint/Sales/UGC)
3. Prioritize: Sales → Questions → Complaints → Compliments → Tags → UGC → Emoji
4. Draft: Use templates, personalize each
5. Review: Check against quality checklist
6. Post: Reply via MCP `reply_to_comment` with `confirm: true`
6. Log: Track in `automation/logs/comment-replies-{{date}}.json`
```

### Weekly Comment Analysis (30 mins)
```
1. Export all comments from past 7 days
2. Analyze:
   - Top questions asked → Content ideas
   - Sentiment trend → Community health
   - Response rate → Engagement quality
   - Unanswered themes → FAQ content
3. Update: FAQ, content calendar, product info
4. Report: Save to `analytics/weekly/comment-analysis-{{week}}.md`
```

## MCP Commands for Comment Management

```bash
# Read all recent comments across posts
instagram-mcp call read_all_comments --args '{"limit": 100}'

# Get comments for specific post
instagram-mcp call get_comments --args '{"media_id": "POST_ID"}'

# Get replies to a comment
instagram-mcp call get_comment_replies --args '{"comment_id": "COMMENT_ID"}'

# Reply to a comment (requires confirm)
instagram-mcp call reply_to_comment --args '{"comment_id": "COMMENT_ID", "message": "Your reply here"}' --confirm

# Hide a comment (reversible)
instagram-mcp call hide_comment --args '{"comment_id": "COMMENT_ID"}'

# Delete a comment (permanent, requires confirm)
instagram-mcp call delete_comment --args '{"comment_id": "COMMENT_ID"}' --confirm

# Private reply to comment (requires confirm, one per comment)
instagram-mcp call private_reply_to_comment --args '{"comment_id": "COMMENT_ID", "message": "Private message"}' --confirm
```

## Escalation Matrix

| Situation | Action | Who | Timeline |
|-----------|--------|-----|----------|
| Legal threat | Screenshot, hide, legal review | Owner/Legal | Immediate |
| PR crisis brewing | Pause auto-replies, crisis plan | Owner/PR | <1 hour |
| Viral negative thread | Don't engage, monitor, statement if needed | Owner | <2 hours |
| Competitor attack | Document, don't engage publicly | Owner | <4 hours |
| Customer data exposed | Immediate DM, report to Meta | Owner/Security | Immediate |
| Spam bot attack | Bulk hide, report, adjust filters | Automation | <30 min |
